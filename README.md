# Site de Belle Partie

Deux pages statiques, publiées par GitHub Pages depuis le dépôt public
[Boisteaub/belle-partie](https://github.com/Boisteaub/belle-partie) :

- `index.html` : présentation courte et lien vers Google Play → https://boisteaub.github.io/belle-partie/
- `confidentialite/index.html` : politique de confidentialité exigée par Google Play →
  https://boisteaub.github.io/belle-partie/confidentialite/

Le dépôt public ne contient que ce dossier, jamais le code de l'appli. Après une modification
ici, publiez-la avec `scripts/publier-site.sh` (la mise en ligne prend une minute).
